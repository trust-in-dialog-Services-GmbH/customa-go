# Customa Go Client

This repository contains the official Go client for [Customa](https://www.customa.de). It is generated automatically using the [OpenAPI Generator](https://openapi-generator.tech) from the OpenAPI Specification of the [Customa REST API](https://docs.customa.biz/rest-api/).

To add the Client to your Go project, run `go get -u github.com/trust-in-dialog-Services-GmbH/customa-go`.
